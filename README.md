# blue-blockgame

광고 없는 8×8 웹 블록 퍼즐. index.html을 브라우저에서 열거나 세 게임 파일을 웹 서버에 올리면 실행됩니다. 설치·빌드·외부 라이브러리는 필요하지 않습니다.

## 게임 방법

- 기본 블록이 놓인 보드의 빈틈을 채우세요.
- 블록을 드래그하거나 선택 후 시작 칸을 눌러 배치합니다.
- 블록을 가볍게 누르면 90도 회전하며, 끌어서 배치합니다. 회전 횟수 제한은 없습니다.
- 가로·세로 줄을 완성하면 지워집니다. 놓기 전 완성될 줄이 강조됩니다.
- 3개를 모두 사용하면 새 블록을 받습니다.
- 3번의 배치 안에 다시 줄을 지우면 콤보가 이어집니다.
- 회전해도 남은 어떤 블록도 놓을 수 없을 때 종료됩니다.
- 최고 기록과 진행 상황은 브라우저에 저장됩니다.
- 소리는 상단에서, 진동은 도움말에서 설정할 수 있습니다. 진동은 지원 기기에서 작동합니다.
- 홈 화면 추가 방법은 도움말을 확인하세요.

기존 저장 기록은 유지됩니다. 시작 블록은 ‘새 게임’부터 적용됩니다.

독립적으로 제작한 퍼즐이며 Block Blast의 공식 제품이 아닙니다.

## 모드 선택

상단 ⚙ 설정에서 기본 모드와 내려오기 모드를 선택합니다. 기본 모드는 줄 제거 후 나머지 블록이 유지됩니다. 내려오기 모드는 가로줄 제거 시 위쪽 줄이 통째로 내려오며 기존 빈칸과 좌우 위치는 유지됩니다. 세로줄은 제거만 하며 주변 블록을 당기지 않습니다. 새로 완성된 줄은 연쇄 제거됩니다. 모드를 변경하면 새 게임이 시작되며 최고 기록은 모드별로 저장됩니다.
