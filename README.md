# blue-blockgame

광고와 로그인 없이 즐길 수 있도록 만든 8×8 웹 블록 퍼즐입니다.

## 실행

`index.html`을 브라우저에서 열면 바로 플레이할 수 있습니다. 별도 설치나 빌드, 외부 라이브러리가 필요하지 않습니다. 웹 서버에 세 파일을 함께 올려서 사용할 수도 있습니다.

## 게임 방법

- 블록 3개를 보드에 드래그해서 놓습니다. 블록 선택 후 시작 칸을 눌러 배치할 수도 있습니다.
- 가로나 세로 한 줄을 채우면 사라집니다.
- 세 블록을 모두 사용하면 새 블록이 나옵니다.
- 3번의 배치 안에 다시 줄을 지우면 콤보가 이어집니다.
- 남은 블록을 어느 것도 놓을 수 없으면 종료됩니다.
- 최고 점수와 진행 상황은 브라우저에 자동 저장됩니다.

## 구성

- `index.html`: 게임 화면
- `style.css`: 휴대폰·PC 반응형 디자인
- `game.js`: 게임 규칙, 드래그 조작, 점수와 저장

독립적으로 제작한 블록 퍼즐이며 Block Blast의 공식 제품이 아닙니다.
